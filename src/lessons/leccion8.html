Lección 8: Sistemas de Múltiples Unidades y Balances de Materia

1. Introducción a los Sistemas de Múltiples Unidades

Diferencia entre procesos de una unidad y múltiples unidades

Un proceso de una sola unidad contiene únicamente un equipo u operación principal. Por ejemplo:

  • Un mezclador.
  • Un divisor.
  • Un evaporador.
  • Un filtro.

En estos casos, el balance de materia se plantea directamente alrededor de ese equipo.

Un proceso de múltiples unidades contiene dos o más equipos conectados mediante corrientes de materia. Por ejemplo:

\[ \text{Mezclador} \rightarrow \text{Reactor} \rightarrow \text{Separador} \]

Cada unidad puede modificar el caudal, la composición o el estado físico de las corrientes.

Procesos industriales complejos

En una planta industrial real, rara vez se utiliza una sola operación unitaria. Generalmente se combinan varias etapas, como:

  • Mezclado.
  • Calentamiento.
  • Reacción.
  • Separación.
  • Filtración.
  • Destilación.
  • Secado.
  • Recirculación.

La interacción entre estas unidades produce corrientes internas que deben analizarse cuidadosamente.

Importancia del análisis por sistemas

Dividir el proceso en sistemas permite:

  • Identificar entradas y salidas.
  • Reducir el número de incógnitas.
  • Elegir balances sencillos.
  • Localizar errores.
  • Determinar corrientes internas.
  • Resolver el proceso de manera ordenada.

Un mismo proceso puede analizarse como un sistema global o dividirse en varios subsistemas.

Aplicación de balances de materia

Para un proceso sin reacción química y en estado estacionario:

\[ \sum \text{Entradas}=\sum \text{Salidas} \]

Para cada componente (i):

\[ \sum \text{Entradas de }i =\sum \text{Salidas de }i \]

Cuando existen varias unidades, estas ecuaciones pueden aplicarse:

  • Al proceso completo.
  • A una unidad individual.
  • A un grupo de unidades.

Ejemplo

Una planta procesa leche mediante:

  • Mezclado.
  • Pasteurización.
  • Enfriamiento.

Cada etapa constituye una unidad distinta, pero todas forman parte del mismo proceso.

2. Diagramas de Flujo de Procesos

Definición

Un diagrama de flujo de procesos, conocido como PFD por sus siglas en inglés, es una representación gráfica de los equipos principales y de las corrientes que los conectan.

Representación gráfica del proceso

En el diagrama, cada equipo se representa mediante un símbolo o figura.

Ejemplos:

  • Tanque.
  • Mezclador.
  • Reactor.
  • Intercambiador de calor.
  • Columna de destilación.
  • Filtro.
  • Bomba.

Las flechas indican la dirección de las corrientes.

Equipos conectados mediante corrientes

Un proceso puede representarse de la siguiente forma:

\[ F \rightarrow \boxed{\text{Mezclador}} \rightarrow \boxed{\text{Evaporador}} \rightarrow P \]

Además pueden aparecer corrientes laterales, recirculaciones o purgas.

Información para balances de materia

Un PFD puede incluir:

  • Número o nombre de cada corriente.
  • Caudal.
  • Temperatura.
  • Presión.
  • Composición.
  • Estado físico.
  • Datos de equipos.
  • Servicios auxiliares principales.

Esta información facilita el planteamiento de balances.

Aplicación en diseño y operación

Los diagramas de flujo se emplean para:

  • Diseñar plantas.
  • Analizar procesos existentes.
  • Capacitar operadores.
  • Detectar fallas.
  • Planear modificaciones.
  • Realizar balances de materia y energía.
  • Identificar puntos de control.

Ejemplo

Una planta de producción de aceite incluye:

  • Tanque de mezcla.
  • Intercambiador de calor.
  • Separador.

El diagrama muestra cómo circulan las corrientes entre estos equipos.

3. Diagramas de Bloques

Definición

Un diagrama de bloques es una representación simplificada del proceso.

Cada bloque representa una operación, una unidad o un conjunto de equipos.

Representación simplificada

No muestra todos los detalles mecánicos.

Ejemplo:

\[ \text{Materia prima} \rightarrow \boxed{\text{Preparación}} \rightarrow \boxed{\text{Separación}} \rightarrow \text{Producto} \]

Cada bloque representa una operación unitaria

Un bloque puede representar:

  • Mezclado.
  • Reacción.
  • Separación.
  • Secado.
  • Filtración.
  • Destilación.
  • Almacenamiento.

Incluso puede representar varias unidades si el análisis no necesita mayor detalle.

Facilita el análisis de procesos complejos

El diagrama de bloques permite:

  • Visualizar la estructura general.
  • Identificar las principales entradas y salidas.
  • Reconocer recirculaciones y purgas.
  • Dividir el proceso en subsistemas.
  • Elegir dónde aplicar los balances.

Ejemplo

En lugar de dibujar todos los equipos de una planta de tratamiento de agua, se representan únicamente tres bloques:

  • Mezcla.
  • Filtración.
  • Desinfección.

4. Comparación entre Diagrama de Flujo y Diagrama de Bloques

Nivel de detalle

El diagrama de bloques es más general y simplificado.

El diagrama de flujo de procesos contiene mayor información técnica.

Característica Diagrama de bloques Diagrama de flujo
Nivel de detalle Bajo Medio o alto
Equipos específicos No siempre Sí
Composiciones Opcionales Frecuentes
Temperaturas y presiones Generalmente no Frecuentes
Uso inicial Comprensión general Diseño y análisis

Ventajas del diagrama de bloques

  • Es fácil de elaborar.
  • Permite comprender rápidamente el proceso.
  • Ayuda a identificar sistemas y subsistemas.
  • Es útil al inicio de un problema.

Ventajas del diagrama de flujo

  • Contiene información cuantitativa.
  • Permite realizar balances detallados.
  • Facilita la operación industrial.
  • Ayuda a identificar corrientes específicas.
  • Es útil para diseño y control.

Aplicaciones prácticas

El diagrama de bloques se utiliza para:

  • Explicaciones generales.
  • Planeación inicial.
  • Análisis conceptual.

El diagrama de flujo se utiliza para:

  • Cálculos de ingeniería.
  • Diseño de plantas.
  • Simulación.
  • Operación y mantenimiento.

Ejemplo

Para explicar un proceso a un nuevo operador se utiliza un diagrama de bloques; para diseñar la planta se emplea un diagrama de flujo detallado.

5. Definición de Sistema en un Proceso

Un sistema es cualquier parte del proceso que se selecciona para su análisis y se separa del resto mediante una frontera real o imaginaria.

Puede incluir:

  • Una unidad.
  • Varias unidades.
  • Todo el proceso.
  • Una sección específica.

Entradas

Son las corrientes que cruzan la frontera hacia el interior del sistema.

Pueden contener:

  • Materias primas.
  • Solventes.
  • Gases.
  • Reactivos.
  • Corrientes recicladas.

Salidas

Son las corrientes que abandonan el sistema.

Pueden ser:

  • Productos.
  • Subproductos.
  • Desechos.
  • Purga.
  • Vapor.
  • Corrientes de recirculación, dependiendo de la frontera elegida.

Frontera del sistema

La frontera define qué corrientes se consideran internas y cuáles externas.

Las corrientes internas no aparecen en el balance global si no cruzan la frontera seleccionada.

Ejemplo

En una línea de producción de jugo, únicamente el tanque mezclador se considera como sistema para realizar el balance de materia.

6. Sistema Global

Definición

El sistema global incluye todas las unidades del proceso dentro de una sola frontera.

Ejemplo:

\[ \boxed{ \text{Mezclador} \rightarrow \text{Evaporador} \rightarrow \text{Filtro} } \]

Solo considera corrientes externas

En el balance global se incluyen únicamente las corrientes que entran o salen del proceso completo.

Las corrientes internas entre equipos no aparecen porque no cruzan la frontera global.

Simplificación del análisis inicial

El sistema global permite eliminar temporalmente muchas incógnitas internas.

Por ejemplo, si una corriente pasa del mezclador al evaporador, esa corriente no aparece en el balance global.

Balance global

Sin reacción ni acumulación:

\[ \sum F_{\text{externas}} =\sum P_{\text{externas}} \]

Para un componente (A):

\[ \sum F_{\text{externas}}w_{A,F} =\sum P_{\text{externas}}w_{A,P} \]

Ejemplo

Una planta con mezclador, evaporador y secador se analiza inicialmente como una sola unidad para calcular el flujo total del producto final.

7. Subsistemas

Definición

Un subsistema es una parte del proceso total seleccionada para realizar un análisis más específico.

Puede ser:

  • Una unidad individual.
  • Dos unidades juntas.
  • Una sección del proceso.

Análisis por unidades individuales

Cada equipo puede tratarse como un sistema independiente.

Ejemplo:

\[ \boxed{\text{Mezclador}} \]

Balance:

\[ F_1+F_2=M \]

Luego:

\[ \boxed{\text{Evaporador}} \]

Balance:

\[ M=P+V \]

Flexibilidad en la resolución

El analista puede elegir diferentes fronteras dependiendo de los datos disponibles.

Una frontera adecuada puede permitir resolver una incógnita sin conocer todas las corrientes internas.

Simplificación del problema

Los subsistemas ayudan a:

  • Separar ecuaciones.
  • Reducir confusión.
  • Identificar variables.
  • Resolver el proceso de forma secuencial.

Ejemplo

Después de resolver el balance global de una planta, se analiza únicamente el evaporador para determinar la cantidad de agua eliminada.

8. Combinación de Subsistemas

En ocasiones conviene agrupar dos o más unidades dentro de una sola frontera.

Ejemplo:

\[ \boxed{ \text{Mezclador} + \text{Evaporador} } \]

Reducción de incógnitas

Al combinar unidades, las corrientes internas desaparecen del balance del subsistema combinado.

Esto puede reducir significativamente el número de incógnitas.

Estrategia para procesos complejos

Una estrategia común es:

  1. Resolver el sistema global.
  2. Formar un subsistema con varias unidades.
  3. Resolver unidades individuales.
  4. Determinar corrientes internas.

No existe una única frontera correcta. Se selecciona la que produzca el balance más conveniente.

Ejemplo

Se consideran conjuntamente un mezclador y un intercambiador de calor como un solo sistema para calcular el flujo hacia el reactor.

9. Selección del Sistema de Análisis

Elección del sistema más conveniente

Debe elegirse una frontera que:

  • Incluya pocas incógnitas.
  • Tenga suficientes datos conocidos.
  • Permita escribir balances independientes.
  • Elimine corrientes internas innecesarias.

Número de incógnitas

Antes de plantear el balance se cuentan las variables desconocidas que cruzan la frontera.

Ejemplos:

  • Caudales desconocidos.
  • Composiciones desconocidas.
  • Cantidades de componentes.
  • Fracciones másicas o molares.

Facilidad para resolver balances

El sistema más grande no siempre es el mejor.

En algunos casos conviene usar el sistema global; en otros, una unidad individual proporciona una ecuación más directa.

La selección debe apoyarse en el análisis de grados de libertad.

Ejemplo

En una planta con cinco equipos, se selecciona inicialmente el sistema global porque solo presenta una corriente desconocida.

10. Grados de Libertad

Los grados de libertad indican si existe suficiente información para resolver el sistema.

\[ GDL=N_I-N_E \]

donde:

  • (N_I): número de incógnitas.
  • (N_E): número de ecuaciones independientes.

Número de incógnitas

Se deben contar únicamente las variables realmente desconocidas.

Una corriente puede introducir varias incógnitas:

  • Caudal total.
  • Fracción de uno o más componentes.
  • Temperatura, si fuera necesaria.
  • Presión, si fuera necesaria.

Número de ecuaciones independientes

Pueden utilizarse:

  • Balance total.
  • Balances por componentes.
  • Suma de fracciones igual a 1.
  • Relaciones entre corrientes.
  • Especificaciones de recuperación.
  • Datos de rendimiento.
  • Relaciones de equilibrio.

Criterio de selección

(GDL=0)

El sistema está correctamente especificado y puede resolverse.

(GDL>0)

Faltan datos o relaciones.

(GDL<0)

Hay datos o ecuaciones adicionales, posiblemente redundantes o contradictorios.

Ejemplo

Un sistema tiene:

  • 3 incógnitas.
  • 3 ecuaciones independientes.

Los grados de libertad son cero y el sistema puede resolverse.

11. Estrategias para Resolver Procesos con Múltiples Unidades

Método por grados de libertad

Consiste en analizar varias fronteras y seleccionar aquella con cero grados de libertad.

Procedimiento:

  1. Elegir una frontera.
  2. Contar incógnitas.
  3. Contar ecuaciones.
  4. Calcular los grados de libertad.
  5. Resolver si (GDL=0).

Método del sistema global

Se comienza con una frontera alrededor de todo el proceso.

Ventajas:

  • Elimina corrientes internas.
  • Reduce incógnitas.
  • Permite encontrar productos o alimentaciones externas.
  • Proporciona una visión general.

Método por unidades individuales

Cada equipo se resuelve por separado.

Es útil cuando:

  • Se conocen las corrientes de entrada de una unidad.
  • Se necesitan corrientes internas.
  • Cada equipo tiene relaciones específicas.

Método combinado

En procesos complejos se combinan las tres estrategias:

  1. Balance global.
  2. Balance de grupos de equipos.
  3. Balance de unidades individuales.

Ejemplo

Se inicia resolviendo el balance global de una planta y posteriormente se calculan los caudales internos de cada equipo.

12. Balance Global de Materia

Para un proceso completo, sin reacción y en estado estacionario:

\[ \sum \dot m_{\text{entrada}} ====\sum \dot m_{\text{salida}} \]

Ejemplo general

Si entran dos corrientes y salen tres:

\[ F_1+F_2=P_1+P_2+P_3 \]

Balance global por componente

Para el componente (A):

\[ F_1w_{A,1}+F_2w_{A,2} =P_1w_{A,P1}+P_2w_{A,P2}+P_3w_{A,P3} \]

Ventaja principal

Las corrientes internas no aparecen en la ecuación global.

Esto permite encontrar cantidades externas antes de estudiar el interior del proceso.

Ejemplo

Entradas:

  • 500 kg/h.
  • 200 kg/h.

Salidas:

  • 300 kg/h.
  • 400 kg/h.

El balance global se cumple.

13. Balances en Subsistemas

Cada subsistema debe cumplir la conservación de la masa.

Para un subsistema sin reacción:

\[ \sum \text{Entradas} =\sum \text{Salidas} \]

Aplicación de balances independientes

Puede plantearse:

  • Un balance total.
  • Un balance por cada componente independiente.
  • Relaciones específicas del equipo.

Determinación de corrientes internas

Las corrientes internas se calculan normalmente después de resolver los flujos externos.

Ejemplo:

Si el sistema global permite determinar el producto final, posteriormente puede analizarse un mezclador para obtener una corriente intermedia.

Conservación de masa

Una corriente interna que sale de un subsistema debe ser igual a la que entra al subsistema siguiente.

No debe asignarse un valor diferente a la misma corriente en dos unidades conectadas.

Ejemplo

Después de obtener el flujo total de salida de una planta, se calcula el flujo que atraviesa únicamente un mezclador.

14. Balances por Componentes

Para cada especie (i):

\[ \sum \dot m_{i,\text{entrada}} =\sum \dot m_{i,\text{salida}} \]

si no hay reacción ni acumulación.

Seguimiento individual de especies

Los balances por componente permiten seguir sustancias como:

  • Agua.
  • Soluto.
  • Sólidos.
  • Solvente.
  • Producto.
  • Contaminante.

Uso de composiciones

Si se conoce la fracción másica:

\[ \dot m_i=w_i\dot m \]

Si se conoce la fracción molar:

\[ \dot n_i=x_i\dot n \]

Número de balances

Para una mezcla de (C) componentes, pueden escribirse hasta (C) balances por componente.

Sin embargo, no todos son independientes si también se utiliza el balance total.

Ejemplo

Una corriente contiene:

  • 40% etanol.
  • 60% agua.

El balance del etanol se realiza de forma independiente al del agua.

15. Balances Independientes

Una ecuación es independiente si aporta información nueva y no puede obtenerse combinando otras ecuaciones.

Evitar ecuaciones redundantes

Para una mezcla binaria sin reacción:

  • Balance total.
  • Balance del componente A.
  • Balance del componente B.

Solo dos de estas tres ecuaciones son independientes.

Esto ocurre porque:

\[ w_A+w_B=1 \]

y el balance total puede obtenerse sumando los balances de A y B.

Número adecuado de ecuaciones

Para (C) componentes no reactivos, existen normalmente (C) balances independientes si no se incluye el balance total como ecuación adicional.

También puede usarse:

  • Un balance total.
  • (C-1) balances por componente.

Resolución eficiente

No conviene escribir ecuaciones innecesarias. Esto puede generar:

  • Sistemas redundantes.
  • Cálculos repetidos.
  • Confusión en los grados de libertad.

Ejemplo

En un sistema con dos componentes se escriben únicamente:

  • Balance de A.
  • Balance de B.

No es necesario escribir un tercer balance total si no aporta nueva información.

16. Consideraciones Especiales para Splitters

Un splitter divide una corriente en varias salidas sin modificar su composición.

Composición constante

Si una entrada (F) se divide en (S_1) y (S_2):

\[ w_{i,F}=w_{i,S1}=w_{i,S2} \]

para todos los componentes.

División del flujo

El balance total es:

\[ F=S_1+S_2 \]

Si existe una fracción de división (\alpha):

\[ S_1=\alpha F \]

\[ S_2=(1-\alpha)F \]

Solo un balance de flujo independiente

Aunque pueden escribirse balances para cada componente, no proporcionan información adicional sobre la división si la composición ya se sabe constante.

Ejemplo:

\[ Fw_A=S_1w_A+S_2w_A \]

Al cancelar (w_A):

\[ F=S_1+S_2 \]

Por eso, en un splitter ideal los balances por componente se reducen al mismo balance total.

Ejemplo

Una corriente de 600 kg/h se divide en dos corrientes de 240 kg/h y 360 kg/h.

Ambas conservan la misma composición.

17. Identificación de Corrientes Conocidas y Desconocidas

Antes de resolver se recomienda construir una tabla.

Corriente Caudal Composición Estado
(F_1) Conocido Conocida Entrada
(F_2) Desconocido Conocida Entrada
(P) Desconocido Desconocida Salida

Variables conocidas

Pueden ser:

  • Caudales.
  • Composiciones.
  • Recuperaciones.
  • Porcentajes.
  • Relaciones entre corrientes.
  • Concentraciones.

Variables por determinar

Pueden incluir:

  • Caudales internos.
  • Composición de productos.
  • Cantidad recirculada.
  • Cantidad purgada.
  • División de corrientes.
  • Recuperación de componentes.

Organización del problema

Una nomenclatura clara evita confusiones.

Ejemplo:

  • (F): alimentación.
  • (R): recirculación.
  • (P): producto.
  • (W): desecho.
  • (M): corriente mezclada.

Ejemplo

En un proceso se conocen:

  • Dos alimentaciones.
  • Dos productos.

Solo falta determinar el caudal de una corriente intermedia.

18. Resolución de un Balance Global

El balance global suele ser el primer paso porque elimina todas las corrientes internas.

Ejemplo

Un proceso recibe:

\[ F=1000;kg/h \]

y produce una corriente de producto (P) y una de desecho (W).

Si:

\[ W=250;kg/h \]

entonces:

\[ F=P+W \]

\[ 1000=P+250 \]

\[ P=750;kg/h \]

Uso del balance total

El balance total permite determinar caudales desconocidos cuando las demás corrientes externas son conocidas.

Primer paso del análisis

Después de encontrar un flujo externo, este valor puede utilizarse en balances de subsistemas para calcular corrientes internas.

Ejemplo

Entradas:

  • 180 kg/h.
  • 70 kg/h.

Salidas:

  • 120 kg/h.
  • 50 kg/h.
  • Producto desconocido.

Producto:

\[ 250-170=80\ kg/h \]

19. Determinación de la Composición de una Corriente

La composición desconocida se obtiene normalmente mediante un balance por componente.

Ejemplo

Dos corrientes se mezclan:

\[ F_1=100;kg/h \]

con:

\[ w_{A,1}=0.20 \]

y:

\[ F_2=200;kg/h \]

con:

\[ w_{A,2}=0.50 \]

El flujo de salida es:

\[ M=100+200=300;kg/h \]

Balance de A:

\[ 100(0.20)+200(0.50)=300w_{A,M} \]

\[ 20+100=300w_{A,M} \]

\[ w_{A,M}=0.40 \]

La corriente mezclada contiene 40% en masa de A.

Fracciones másicas

Debe cumplirse:

\[ \sum_i w_i=1 \]

y:

\[ 0\leq w_i\leq1 \]

Conservación de materia

La masa del componente en la corriente resultante debe ser igual a la suma de las masas de ese componente en las entradas.

Ejemplo

Una corriente contiene únicamente:

  • Aceite.
  • Agua.

Después de resolver el balance del aceite se obtiene una composición de 35% en masa de aceite.

20. Resolución Secuencial de un Proceso

La resolución secuencial consiste en avanzar de un sistema resoluble al siguiente.

Paso 1: resolver el sistema global

Se determinan las corrientes externas desconocidas.

Paso 2: elegir un subsistema resoluble

Se busca una unidad o grupo de unidades con cero grados de libertad.

Paso 3: obtener una corriente interna

El resultado del subsistema se utiliza como dato para otra unidad.

Paso 4: continuar hasta completar el proceso

El procedimiento se repite hasta calcular todas las corrientes y composiciones.

Ejemplo de secuencia

\[ \text{Mezclador} \rightarrow \text{Evaporador} \rightarrow \text{Filtro} \]

Una posible estrategia sería:

  1. Balance global para calcular el producto final.
  2. Balance del filtro para encontrar la alimentación del filtro.
  3. Balance del evaporador para calcular el vapor.
  4. Balance del mezclador para obtener una alimentación desconocida.

El orden depende de los datos disponibles, no necesariamente de la dirección física del proceso.

Ejemplo

Una planta tiene:

1. Mezclador.

2. Evaporador.

3. Separador.

Primero se determina el flujo total de salida y luego se calculan los caudales entre cada equipo.

21. Validación de Resultados

Comprobación del balance total

Debe verificarse para:

  • El proceso completo.
  • Cada unidad.
  • Cada subsistema importante.

\[ \sum \text{Entradas} - \sum \text{Salidas} =0 \]

en estado estacionario y sin reacción.

Revisión de balances por componente

Para cada especie:

\[ \sum \text{Entradas}_i - \sum \text{Salidas}_i =0 \]

Verificación de unidades

Todas las corrientes deben utilizar una base consistente:

  • kg/h.
  • mol/s.
  • kmol/h.

No debe mezclarse masa y moles sin usar peso molecular.

Consistencia física

Debe comprobarse que:

  • No existan caudales negativos.
  • Las fracciones estén entre 0 y 1.
  • Las fracciones sumen 1.
  • La misma corriente tenga iguales datos en equipos conectados.
  • La masa de un componente no supere la masa total.
  • Las recuperaciones estén entre 0 y 100%.

Ejemplo

Si la suma de las salidas es mayor que las entradas sin reacción química, existe un error en los cálculos.

22. Aplicaciones Industriales

Plantas químicas

Los sistemas de múltiples unidades se utilizan en:

  • Producción de ácidos.
  • Refinación.
  • Fabricación de polímeros.
  • Separación de solventes.
  • Tratamiento de corrientes residuales.

Procesos farmacéuticos

Incluyen:

  • Mezclado de materias primas.
  • Reacción.

23. Resumen Integrador

Diagramas de flujo

Representan equipos y corrientes con información detallada del proceso.

Diagramas de bloques

Muestran de manera simplificada las principales operaciones y conexiones.

Sistema global

Incluye todas las unidades y solo considera corrientes externas.

\[ \sum \text{Entradas externas} =\sum \text{Salidas externas} \]

Subsistemas

Permiten analizar unidades individuales o grupos de equipos.

Grados de libertad

Determinan si una frontera puede resolverse:

\[ GDL =\text{Incógnitas}-\text{Ecuaciones independientes} \]

Balances globales

Son útiles para calcular corrientes externas sin considerar las corrientes internas.

Balances por componentes

Permiten seguir individualmente cada sustancia:

\[ \sum \text{Entrada}_i =\sum \text{Salida}_i \]

Resolución secuencial

Consiste en:

  1. Resolver el sistema global.
  2. Seleccionar subsistemas con cero grados de libertad.
  3. Determinar corrientes internas.
  4. Continuar hasta completar el proceso.
  5. Verificar todos los resultados.

Ejemplo integrador

Una planta recibe dos corrientes de alimentación:

  • 250 kg/h de una solución salina.
  • 150 kg/h de agua.

El proceso incluye un mezclador, un evaporador y un separador. Primero se realiza el balance global para determinar el flujo total de producto; posteriormente se analizan cada una de las unidades para calcular las corrientes internas y las composiciones. Esta estrategia permite resolver procesos con múltiples equipos de manera ordenada y eficiente, siguiendo la metodología presentada en la lección.

Conclusión general

Los procesos de múltiples unidades requieren una selección cuidadosa de las fronteras de análisis. El sistema global permite simplificar inicialmente el problema al eliminar corrientes internas, mientras que los subsistemas permiten determinar los detalles de cada operación. Los diagramas de bloques y de flujo facilitan la organización de la información, y el análisis de grados de libertad permite identificar qué sistema puede resolverse. La combinación de balances totales, balances por componentes y una resolución secuencial constituye una estrategia eficaz para analizar procesos químicos, farmacéuticos, alimentarios y biotecnológicos complejos.
