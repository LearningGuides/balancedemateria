Lección 9: Estrategias para Resolver Procesos con Múltiples Unidades

1. Introducción: Estrategias para Resolver Procesos con Múltiples Unidades

El análisis de procesos con múltiples unidades es una continuación natural de los balances de materia aplicados a sistemas sin reacción química.

En estos procesos, varias operaciones unitarias se encuentran conectadas mediante corrientes internas. Por ejemplo:

\[ \text{Mezclador} \rightarrow \text{Evaporador} \rightarrow \text{Filtro} \rightarrow \text{Secador} \]

Aunque el principio fundamental sigue siendo la conservación de la masa, la dificultad aumenta porque aparecen:

  • Más corrientes.
  • Más composiciones.
  • Más variables desconocidas.
  • Dependencias entre equipos.
  • Posibles recirculaciones, purgas y divisiones de flujo.

La clave no consiste únicamente en escribir muchos balances, sino en seleccionar correctamente el sistema de análisis.

Continuación del análisis de procesos sin reacción

Para un sistema sin reacción química:

\[ \text{Entrada}-\text{Salida}=\text{Acumulación} \]

Si además opera en estado estacionario:

\[ \text{Acumulación}=0 \]

por tanto:

\[ \boxed{\text{Entrada}=\text{Salida}} \]

Para cada componente (i):

\[ \boxed{ \sum \dot m_{i,\text{entrada}} ==============================

\sum \dot m_{i,\text{salida}} } \]

Estas ecuaciones pueden aplicarse a:

  • Todo el proceso.
  • Una unidad individual.
  • Dos o más unidades combinadas.
  • Una sección específica de la planta.

Importancia de seleccionar el sistema

Una frontera bien elegida puede eliminar corrientes internas y reducir el número de incógnitas.

Una frontera poco conveniente puede producir un sistema con demasiadas variables desconocidas.

Por eso, antes de plantear ecuaciones debe preguntarse:

  1. ¿Qué corrientes cruzan la frontera?
  2. ¿Cuántas incógnitas aparecen?
  3. ¿Cuántos balances independientes pueden escribirse?
  4. ¿Existe información suficiente para resolverlos?
  5. ¿Conviene analizar una unidad o combinar varias?

Resolución mediante balances sucesivos

En muchos procesos no es posible encontrar todas las variables mediante una sola ecuación global. Se emplea entonces una resolución sucesiva:

  1. Se selecciona un sistema resoluble.
  2. Se calculan algunas corrientes.
  3. Los resultados se convierten en datos conocidos.
  4. Se selecciona otro sistema.
  5. Se repite el procedimiento.

Esta estrategia se denomina resolución secuencial.

Estrategias alternativas al balance global

El balance global suele ser útil, pero no siempre es el mejor punto de partida.

También puede iniciarse el análisis mediante:

  • Una unidad individual.
  • La última unidad del proceso.
  • Un subsistema combinado.
  • Una corriente de producto conocida.
  • Un equipo con pocas incógnitas.
  • Un conjunto de ecuaciones simultáneas.

La estrategia correcta depende de la estructura del proceso y de los datos disponibles.

Ejemplo

Una planta de tratamiento de aire cuenta con un absorbedor, un secador y un filtro. No se conocen todas las corrientes del proceso, por lo que se debe decidir en qué unidad iniciar los balances para obtener las variables desconocidas.

2. Criterios para Seleccionar el Primer Sistema de Análisis

El primer sistema debe elegirse con base en criterios cuantitativos y prácticos.

Número de incógnitas

Se deben contar todas las variables desconocidas que aparecen en las corrientes que cruzan la frontera.

Una corriente puede tener como incógnitas:

  • Flujo total.
  • Fracción másica de uno o más componentes.
  • Fracción molar.
  • Cantidad de sólidos.
  • Cantidad de solvente.
  • Humedad.
  • Recuperación.

Ejemplo:

Una corriente binaria desconocida puede requerir:

  • Su caudal total (F).
  • La fracción másica de A, (w_A).

La fracción de B no es independiente porque:

\[ w_B=1-w_A \]

Por tanto, esa corriente introduce dos incógnitas independientes.

Número de ecuaciones independientes

En un sistema sin reacción pueden escribirse balances por componente.

Para una mezcla de (N) componentes existen normalmente (N) balances independientes.

También puede utilizarse:

  • Un balance total.
  • (N-1) balances por componente.

No deben contarse como independientes simultáneamente:

  • El balance total.
  • Todos los balances de componentes.

Esto se debe a que el balance total es la suma de los balances individuales.

Información disponible

Debe revisarse si se conocen:

  • Flujos de alimentación.
  • Composiciones.
  • Relaciones de división.
  • Recuperaciones.
  • Humedades.
  • Porcentajes de evaporación.
  • Concentraciones de producto.
  • Relaciones entre corrientes.

Una unidad con pocos flujos conocidos puede seguir siendo irresoluble si sus composiciones también son desconocidas.

Viabilidad del sistema seleccionado

La viabilidad puede evaluarse mediante los grados de libertad:

\[ \boxed{ GDL=N_I-N_E } \]

donde:

  • (N_I): número de incógnitas.
  • (N_E): número de ecuaciones independientes.

Interpretación:

\[ GDL=0 \]

El sistema puede resolverse.

\[ GDL>0 \]

Falta información.

\[ GDL<0 \]

Existen ecuaciones o datos redundantes, o posiblemente inconsistentes.

Ejemplo

En una planta de producción de etanol existen cuatro equipos conectados. Solo el primer equipo tiene suficientes datos de alimentación y composición, por lo que se selecciona como punto inicial del análisis.

3. Resolución de Balances en una Unidad Individual

Analizar una unidad individual es conveniente cuando sus entradas, salidas y relaciones están suficientemente especificadas.

Balance total

Para una unidad sin reacción y en estado estacionario:

\[ \sum \dot m_{\text{entrada}} ============================

\sum \dot m_{\text{salida}} \]

Ejemplo, para un mezclador:

\[ F_1+F_2=M \]

Para un separador:

\[ F=P_1+P_2 \]

Balances por componente

Para el componente A:

\[ \sum F_jw_{A,j} ===============

\sum P_kw_{A,k} \]

Para un mezclador con dos entradas:

\[ F_1w_{A,1}+F_2w_{A,2} =====================

Mw_{A,M} \]

Selección de la base de cálculo

Si las corrientes se expresan como flujos reales, puede trabajarse con:

\[ kg/h \]

Si solo se conocen composiciones porcentuales, puede elegirse una base como:

\[ 100;kg\text{ de alimentación} \]

La base no modifica las composiciones; solo facilita los cálculos.

Determinación de corrientes desconocidas

Una vez planteadas las ecuaciones, se despejan:

  • Caudales.
  • Composiciones.
  • Cantidades de componentes.
  • Relaciones entre corrientes.

Es importante no resolver automáticamente todas las unidades en el orden físico del proceso. Debe comenzar con la unidad que tenga cero grados de libertad.

Ejemplo

Un humidificador recibe aire seco y agua líquida. Mediante un balance total y un balance de vapor de agua se determina el flujo de aire humidificado.

4. Uso de la Base de Cálculo

La base de cálculo es una cantidad de referencia elegida para transformar composiciones relativas en cantidades absolutas.

Selección de una base conveniente

Algunas bases comunes son:

\[ 100;kg\text{ de mezcla} \]

\[ 100;kmol\text{ de mezcla} \]

\[ 1;h\text{ de operación} \]

\[ 1000;kg/h\text{ de alimentación} \]

Una base conveniente debe:

  • Evitar decimales innecesarios.
  • Ser compatible con las composiciones dadas.
  • Facilitar conversiones.
  • Mantener coherencia con el problema.

Flujo horario

Si el proceso es continuo, suele ser conveniente usar una base temporal:

\[ 1;h \]

De esta forma, un caudal de:

\[ 500;kg/h \]

equivale a procesar:

\[ 500;kg \]

durante una hora.

Consistencia de unidades

Todos los balances deben emplear la misma base.

No debe combinarse directamente:

\[ kg/h \]

con:

\[ kg/día \]

sin convertir.

Por ejemplo:

\[ 2400;kg/día ===========

Ejemplo

Se establece una base de 500 kg/h de alimentación para calcular los caudales de todas las corrientes de un sistema de concentración de soluciones.

\frac{2400}{24}

100;kg/h \]

Simplificación de cálculos

Si una corriente contiene:

  • 40% de A.
  • 35% de B.
  • 25% de C.

Elegir una base de 100 kg produce directamente:

\[ m_A=40;kg \]

\[ m_B=35;kg \]

\[ m_C=25;kg \]

Ejemplo

Una mezcla de agua y sal entra a un tanque separador. El balance de sal permite calcular la cantidad de solución concentrada producida.

5. Aplicación de Balances por Componentes

Los balances por componente siguen individualmente cada especie.

Conservación individual

Para un componente (i), sin reacción:

\[ \sum m_{i,\text{entrada}} =========================

\sum m_{i,\text{salida}} \]

En flujo continuo:

\[ \sum \dot m_{i,\text{entrada}} ==============================

\sum \dot m_{i,\text{salida}} \]

Relación entre composición y flujo

La cantidad de un componente se calcula como:

\[ \dot m_i=w_i\dot m \]

donde:

  • (w_i): fracción másica.
  • (\dot m): flujo total.
  • (\dot m_i): flujo del componente.

En base molar:

\[ \dot n_i=x_i\dot n \]

Obtención de variables desconocidas

Considérese una separación binaria:

\[ F=D+B \]

Para el componente A:

\[ Fw_{A,F}=Dw_{A,D}+Bw_{A,B} \]

Si se conocen (F), (w_{A,F}), (w_{A,D}) y (w_{A,B}), pueden determinarse (D) y (B) resolviendo simultáneamente ambas ecuaciones.

Ejemplo

Se analizan conjuntamente un evaporador y un condensador para calcular únicamente los flujos de entrada y salida, ignorando las corrientes internas entre ambos equipos.

6. Selección de un Subsistema Combinado

Un subsistema combinado contiene dos o más unidades dentro de una misma frontera.

Agrupación de varias unidades

Supóngase el proceso:

\[ F \rightarrow \boxed{\text{Mezclador}} \rightarrow M \rightarrow \boxed{\text{Evaporador}} \rightarrow P+V \]

Si se agrupan mezclador y evaporador, la corriente (M) queda dentro de la frontera.

Eliminación de corrientes internas

Para el subsistema combinado:

\[ F_1+F_2=P+V \]

La corriente intermedia (M) no aparece porque no cruza la frontera.

Reducción de incógnitas

Si (M) era desconocida, agrupar las unidades elimina temporalmente esa variable.

Esto puede transformar un sistema irresoluble en uno con:

\[ GDL=0 \]

Simplificación del problema

Los subsistemas combinados son especialmente útiles cuando:

  • La corriente entre equipos es desconocida.
  • Las entradas externas son conocidas.
  • Los productos externos tienen datos disponibles.
  • Se desea calcular primero una corriente global.

Ejemplo

Un sistema de separación produce dos corrientes de salida. Utilizando un balance total y un balance del componente principal se determinan ambos caudales.

7. Resolución Simultánea de Ecuaciones de Balance

En muchos casos, una sola ecuación no permite encontrar todas las incógnitas.

Balance total

Para una unidad con una entrada y dos salidas:

\[ F=P_1+P_2 \]

Balance por componente

Para el componente A:

\[ Fw_{A,F} ========

P_1w_{A,1} + P_2w_{A,2} \]

Sistema de ecuaciones

Si (P_1) y (P_2) son desconocidos:

\[ P_1+P_2=F \]

\[ w_{A,1}P_1+w_{A,2}P_2=Fw_{A,F} \]

Estas ecuaciones deben resolverse simultáneamente.

Ejemplo

Una alimentación de 1000 kg/h contiene 30% de A y se separa en:

  • Un producto con 60% de A.
  • Un residuo con 10% de A.

Balance total:

\[ 1000=P+R \]

Balance de A:

\[ 1000(0.30)=P(0.60)+R(0.10) \]

Sustituyendo:

\[ R=1000-P \]

\[ 300=0.60P+0.10(1000-P) \]

\[ 300=0.60P+100-0.10P \]

\[ 200=0.50P \]

\[ P=400;kg/h \]

Por tanto:

\[ R=600;kg/h \]

Verificación:

\[ 400(0.60)+600(0.10)=240+60=300;kg/h \]

Ejemplo

En una planta de procesamiento de leche se decide comenzar el análisis en el concentrador porque es la unidad con mayor cantidad de información conocida.

8. Importancia de Elegir el Sistema Correcto

La selección de la frontera puede determinar si un problema es sencillo o innecesariamente complicado.

Reducción de complejidad

Un sistema adecuado:

  • Elimina corrientes internas.
  • Reduce ecuaciones.
  • Disminuye variables.
  • Facilita la interpretación física.

Disminución del número de incógnitas

Supóngase que dos equipos están conectados mediante una corriente con flujo y composición desconocidos.

Si se analizan por separado, esa corriente introduce varias incógnitas.

Si se agrupan, desaparece del balance combinado.

Estrategia de resolución

Una buena estrategia busca sucesivamente sistemas con:

\[ GDL=0 \]

No es recomendable comenzar a despejar ecuaciones antes de comprobar si el sistema está suficientemente especificado.

Optimización del procedimiento

Elegir bien el sistema permite:

  • Reducir cálculos.
  • Evitar ecuaciones redundantes.
  • Disminuir errores.
  • Obtener resultados en un orden lógico.
  • Facilitar la validación.

Ejemplo

En una planta de reciclaje de solventes solo se conoce el flujo del producto final. El balance global no permite resolver el problema y es necesario comenzar desde una unidad específica.

9. Procesos donde el Balance Global No es Suficiente

El balance global elimina todas las corrientes internas, pero a veces conserva demasiadas incógnitas externas.

Limitaciones del balance global

Considérese un proceso con:

  • Dos alimentaciones desconocidas.
  • Dos productos desconocidos.
  • Composiciones parcialmente desconocidas.

Aunque se planteen balances globales, puede no existir información suficiente para resolver todas las variables.

Exceso de incógnitas

Si el sistema global tiene:

\[ N_I=5 \]

y solo pueden escribirse:

\[ N_E=3 \]

entonces:

\[ GDL=5-3=2 \]

El balance global no es resoluble por sí solo.

Necesidad de balances locales

Puede existir información específica de una unidad, como:

  • Una relación de división.
  • Una humedad de torta.
  • Un porcentaje de evaporación.
  • Una recuperación.
  • Una composición de salida.
  • Una concentración de producto.

Esta información solo puede aprovecharse mediante balances locales.

Análisis secuencial

Una estrategia posible es:

  1. Resolver una unidad con datos suficientes.
  2. Calcular una corriente interna.
  3. Usarla en un subsistema combinado.
  4. Continuar hacia otras unidades.
  5. Aplicar el balance global como comprobación.

Ejemplo

Una planta de cristalización produce 800 kg/h de cristales. A partir de este dato se determina el flujo de alimentación hacia el cristalizador.

10. Estrategias para Iniciar el Análisis desde la Corriente de Producto

No siempre debe comenzarse desde la alimentación.

Disponibilidad de datos del producto

En muchos problemas se especifica:

  • El flujo de producto.
  • Su pureza.
  • Su contenido de humedad.
  • La recuperación deseada.
  • La composición del residuo.

Estos datos pueden hacer que la última unidad sea la más fácil de resolver.

Análisis inverso del proceso

El análisis inverso consiste en avanzar desde el producto hacia las unidades anteriores.

Ejemplo:

\[ F \rightarrow U_1 \rightarrow U_2 \rightarrow P \]

Si (P) y la operación de (U_2) están completamente especificados, puede calcularse la alimentación de (U_2). Después, esa corriente se utiliza para resolver (U_1).

Resolución desde la última unidad

Es común en procesos de:

  • Secado.
  • Filtración.
  • Cristalización.
  • Evaporación.
  • Destilación.
  • Concentración.

Por ejemplo, si se conoce la masa de sólido seco en el producto y su humedad, puede calcularse primero la torta húmeda y después la alimentación al filtro.

Ejemplo

Después de resolver el balance del cristalizador, los resultados obtenidos se utilizan para calcular las corrientes del evaporador conectado aguas arriba.

11. Resolución Secuencial Unidad por Unidad

La resolución secuencial consiste en calcular una unidad a la vez.

Avance progresivo

Cada etapa produce nueva información.

Una secuencia típica es:

\[ \text{Unidad resoluble} \rightarrow \text{corriente calculada} \rightarrow \text{siguiente unidad resoluble} \]

Uso de resultados previos

Una corriente inicialmente desconocida puede convertirse en conocida después de resolver otra unidad.

Por ejemplo:

  1. El secador permite calcular su alimentación húmeda.
  2. Esa alimentación es la salida del filtro.
  3. El filtro puede entonces resolverse.
  4. Su alimentación permite analizar el mezclador anterior.

Dependencia entre unidades

Los equipos están conectados por corrientes compartidas.

La salida de una unidad es la entrada de la siguiente:

\[ \dot m_{\text{salida de }U_1} =============================

\dot m_{\text{entrada a }U_2} \]

La composición también debe ser idéntica.

Cálculo de corrientes internas

Las corrientes internas suelen determinarse después de calcular flujos externos o productos conocidos.

El orden de resolución puede ser:

  • Hacia adelante.
  • Hacia atrás.
  • Desde el centro.
  • Mediante subsistemas combinados.

Ejemplo

En una corriente sólida se conoce el porcentaje de sólidos, pero no la distribución entre humedad e impurezas. Se plantea una variable para determinar ambas composiciones mediante balances.

12. Determinación de Composiciones Desconocidas

Una composición desconocida se representa mediante una variable.

Fracciones másicas

Para una corriente binaria:

\[ w_A=x \]

\[ w_B=1-x \]

Para una corriente de tres componentes:

\[ w_A+w_B+w_C=1 \]

Suposición de variables

No significa asignar un valor arbitrario. Significa representar la incógnita algebraicamente.

Ejemplo:

\[ w_{A,P}=x \]

Entonces:

\[ w_{B,P}=1-x \]

en una mezcla binaria.

Balances por componente

La variable puede determinarse mediante:

\[ \sum F_jw_{A,j} ===============

\sum P_kw_{A,k} \]

Verificación de composiciones

Toda composición debe cumplir:

\[ 0\leq w_i\leq1 \]

y:

\[ \sum_iw_i=1 \]

Si una fracción resulta negativa o mayor que 1, existe un error en:

  • Los datos.
  • Las ecuaciones.
  • Las unidades.
  • La selección de la base.
  • La interpretación del proceso.

Ejemplo

Una corriente contiene proteína, agua y grasa. A partir de balances de proteína y agua se determina la composición completa de la mezcla.

13. Cálculo de Corrientes con Tres Componentes

Los sistemas de tres componentes requieren seguir individualmente cada especie.

Mezclas multicomponente

Considérese una corriente con A, B y C:

\[ w_A+w_B+w_C=1 \]

Si se conocen dos fracciones, la tercera se calcula como:

\[ w_C=1-w_A-w_B \]

Conservación individual

Para una unidad sin reacción:

\[ \sum \dot m_A^{entrada} =======================

\sum \dot m_A^{salida} \]

\[ \sum \dot m_B^{entrada} =======================

\sum \dot m_B^{salida} \]

\[ \sum \dot m_C^{entrada} =======================

\sum \dot m_C^{salida} \]

Restricción de suma de fracciones

Para cada corriente:

\[ w_A+w_B+w_C=1 \]

Esta relación reduce el número de composiciones independientes.

Una corriente ternaria requiere:

  • Un flujo total.
  • Dos fracciones independientes.

La tercera fracción se obtiene por diferencia.

Ejemplo de mezcla ternaria

Se mezclan:

Corriente 1

\[ F_1=100;kg/h \]

\[ w_{A,1}=0.50,\quad w_{B,1}=0.30,\quad w_{C,1}=0.20 \]

Corriente 2

\[ F_2=200;kg/h \]

\[ w_{A,2}=0.10,\quad w_{B,2}=0.40,\quad w_{C,2}=0.50 \]

Balance total:

\[ M=100+200=300;kg/h \]

Balance de A:

\[ m_A=100(0.50)+200(0.10)=70;kg/h \]

\[ w_{A,M}=\frac{70}{300}=0.2333 \]

Balance de B:

\[ m_B=100(0.30)+200(0.40)=110;kg/h \]

\[ w_{B,M}=\frac{110}{300}=0.3667 \]

Balance de C:

\[ m_C=100(0.20)+200(0.50)=120;kg/h \]

\[ w_{C,M}=\frac{120}{300}=0.4000 \]

Verificación:

\[ 0.2333+0.3667+0.4000=1 \]

Ejemplo

Una línea de producción está formada por un mezclador, un filtro y un secador. Cada balance utiliza los resultados obtenidos en la unidad anterior.

14. Análisis de Equipos en Serie

Los equipos en serie están conectados de modo que la salida de uno alimenta al siguiente.

Resolución consecutiva

Si las unidades pueden resolverse en la dirección del flujo:

\[ U_1\rightarrow U_2\rightarrow U_3 \]

se calcula primero (U_1), después (U_2) y finalmente (U_3).

Sin embargo, si los datos están disponibles en el producto final, puede resolverse en sentido inverso:

\[ U_3\rightarrow U_2\rightarrow U_1 \]

desde el punto de vista matemático.

Dependencia entre equipos

Una corriente calculada incorrectamente afecta todas las unidades posteriores.

Por eso debe verificarse cada paso antes de continuar.

Propagación de resultados

Si una corriente tiene:

\[ F=500;kg/h \]

y:

\[ w_A=0.40 \]

estos valores deben mantenerse cuando la corriente se use como entrada de la unidad siguiente.

Organización del procedimiento

Es recomendable elaborar una tabla:

Corriente Flujo (w_A) (w_B) (w_C) Estado
1 Conocido Conocido Conocido Conocido Dato
2 Calculado Calculado Calculado Calculado Resultado
3 Desconocido Parcial Parcial Parcial Pendiente

Esto ayuda a observar qué unidad se vuelve resoluble después de cada cálculo.

Ejemplo

Una planta recupera cobre a partir de una solución acuosa. Comparando el cobre alimentado con el cobre obtenido como producto se calcula el porcentaje de recuperación.

15. Determinación del Rendimiento de Recuperación

La recuperación mide la fracción del componente alimentado que aparece en la corriente de producto deseada.

Recuperación de producto

Para el componente A:

\[ \boxed{ R_A= \frac{\text{cantidad de A en el producto}} {\text{cantidad de A en la alimentación}} } \]

En porcentaje:

\[ \boxed{ %R_A= \frac{\dot m_{A,P}} {\dot m_{A,F}} \times100 } \]

Balance global del componente

Si no hay reacción:

\[ \dot m_{A,F} ============

\dot m_{A,P} + \dot m_{A,R} \]

donde (R) representa el residuo o pérdida.

Relación entre alimentación y producto

Usando fracciones másicas:

\[ \dot m_{A,F}=Fw_{A,F} \]

\[ \dot m_{A,P}=Pw_{A,P} \]

Por tanto:

\[ \boxed{ %R_A= \frac{Pw_{A,P}} {Fw_{A,F}} \times100 } \]

Ejemplo

Una alimentación de 1000 kg/h contiene 20% de A.

El producto es de 300 kg/h y contiene 60% de A.

Cantidad alimentada de A:

\[ m_{A,F}=1000(0.20)=200;kg/h \]

Cantidad de A en el producto:

\[ m_{A,P}=300(0.60)=180;kg/h \]

Recuperación:

\[ %R_A= \frac{180}{200}(100) ====================

90% \]

Eficiencia del proceso

Una recuperación alta no siempre significa alta pureza.

Deben distinguirse:

Recuperación

Cuánto del componente alimentado se recupera.

Pureza

Qué proporción del producto corresponde al componente de interés.

En el ejemplo:

\[ \text{Recuperación}=90% \]

\[ \text{Pureza}=60% \]

Son conceptos diferentes.

Ejemplo

En una planta de alimentos con seis operaciones unitarias se elabora una estrategia donde primero se identifican las unidades con menor número de incógnitas antes de efectuar cualquier cálculo.

16. Estrategias Generales para Resolver Procesos Complejos

Identificación del sistema adecuado

Antes de escribir ecuaciones:

  1. Dibujar el diagrama.
  2. Numerar corrientes.
  3. Identificar componentes.
  4. Marcar datos conocidos.
  5. Marcar incógnitas.
  6. Probar distintas fronteras.
  7. Calcular grados de libertad.

Resolución por etapas

Una secuencia recomendable es:

  1. Buscar una unidad con cero grados de libertad.
  2. Resolverla.
  3. Actualizar el diagrama.
  4. Buscar el siguiente sistema resoluble.
  5. Combinar unidades cuando convenga.
  6. Usar el balance global como herramienta o comprobación.

Validación de resultados

Después de cada etapa debe verificarse:

Balance total

\[ \sum \text{Entradas} ====================

\sum \text{Salidas} \]

Balance por componente

\[ \sum \text{Entradas}_i ======================

\sum \text{Salidas}_i \]

Suma de composiciones

\[ \sum_iw_i=1 \]

Unidades

Todos los términos de una ecuación deben tener unidades compatibles.

Significado físico

  • Flujos positivos.
  • Fracciones entre 0 y 1.
  • Recuperaciones entre 0 y 100%.
  • Productos con composiciones razonables.

Experiencia en selección de sistemas

La selección de fronteras mejora con la práctica.

Algunas recomendaciones son:

  • No asumir que el sistema global siempre es el mejor.
  • Comenzar por donde haya más información.
  • Eliminar corrientes internas mediante subsistemas combinados.
  • Resolver desde el producto cuando esté mejor especificado.
  • No escribir ecuaciones antes de contar incógnitas.
  • Usar balances del componente más fácil de seguir.
  • Aprovechar componentes que aparezcan en pocas corrientes.

Un componente que entra o sale por una sola corriente puede producir una ecuación especialmente sencilla.

Ejemplo integrador

Una planta de producción de jugo concentrado está compuesta por un extractor, un clarificador, un evaporador y un secador. Se conoce únicamente el flujo del producto final y algunas composiciones intermedias. El análisis comienza en el secador, continúa hacia el evaporador y luego hacia las unidades anteriores. Mediante balances de materia en cada etapa se determinan todas las corrientes internas y finalmente se calcula el porcentaje de recuperación del jugo concentrado.

17. Resumen Integrador

Selección estratégica del sistema

El proceso puede analizarse mediante:

  • Sistema global.
  • Unidad individual.
  • Subsistema combinado.
  • Resolución desde el producto.
  • Resolución secuencial.

La frontera adecuada es aquella que produce suficientes ecuaciones independientes para las incógnitas presentes.

Balances totales y por componentes

Para estado estacionario y sin reacción:

\[ \sum \text{Entradas} ====================

\sum \text{Salidas} \]

Para cada componente:

\[ \sum \text{Entradas}_i ======================

\sum \text{Salidas}_i \]

La cantidad de componente se calcula mediante:

\[ \dot m_i=w_i\dot m \]

o:

\[ \dot n_i=x_i\dot n \]

Resolución secuencial

Consiste en:

  1. Resolver un sistema con cero grados de libertad.
  2. Obtener una nueva corriente conocida.
  3. Utilizarla en otro sistema.
  4. Continuar hasta determinar todas las variables.

Uso de subsistemas

Agrupar unidades permite eliminar corrientes internas:

\[ \text{Entradas externas al subsistema} ======================================

\text{Salidas externas del subsistema} \]

Esto reduce el número de incógnitas.

Cálculo de composiciones

Para una corriente multicomponente:

\[ \sum_iw_i=1 \]

En una mezcla ternaria solo dos fracciones son independientes.

Las composiciones desconocidas se determinan con balances individuales.

Determinación de recuperación

La recuperación del componente A es:

\[ \boxed{ %R_A= \frac{Pw_{A,P}} {Fw_{A,F}} \times100 } \]

Debe diferenciarse de la pureza del producto.

Procedimiento general recomendado

  1. Leer cuidadosamente el problema.
  2. Dibujar el diagrama de flujo.
  3. Numerar todas las corrientes.
  4. Elegir una base de cálculo.
  5. Convertir unidades.
  6. Identificar componentes.
  7. Marcar variables conocidas y desconocidas.
  8. Probar diferentes fronteras.
  9. Realizar el análisis de grados de libertad.
  10. Seleccionar un sistema con (GDL=0).
  11. Escribir balances independientes.
  12. Resolver las ecuaciones.
  13. Actualizar los datos del diagrama.
  14. Seleccionar el siguiente sistema.
  15. Repetir hasta determinar todas las corrientes.
  16. Calcular purezas y recuperaciones.
  17. Verificar balances totales y por componente.
  18. Comprobar unidades y consistencia física.

Conclusión general

La resolución de procesos con múltiples unidades no depende únicamente de aplicar la ecuación de conservación de la masa, sino de elegir estratégicamente la frontera de análisis. El balance global es útil para eliminar corrientes internas, pero puede ser insuficiente cuando existen demasiadas incógnitas externas. En esos casos deben utilizarse balances locales, subsistemas combinados o una resolución secuencial desde la unidad que tenga más información disponible.

El análisis de grados de libertad permite determinar si una unidad o subsistema puede resolverse. Los balances totales y por componentes, junto con una base de cálculo consistente, permiten calcular flujos, composiciones y recuperaciones. Una resolución ordenada, acompañada de verificaciones continuas, reduce errores y facilita el análisis de procesos industriales complejos.
